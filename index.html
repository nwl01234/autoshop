AutoShop — этот магазин

Магазин сам является проектом: премиальный фронт на GitHub Pages + Telegram-бот, синхронизирующий остатки в репозиторий через GitHub API.

▶ Как устроено

Каталог

Кнопка «Купить» собирает корзину → открывает Telegram-бота с твоей корзиной → бот оформляет и принимает оплату. Оплата — точка интеграции любого платёжного провайдера.

Как устроена автономность

1 · Выбор

Остатки лежат в репозитории сайта; бот держит их синхронно через GitHub API.

2 · Корзина

Собирается на сайте (localStorage) или в чате бота (FSM).

3 · Передача

«Оплатить» кодирует корзину в ссылке-начале бота — бот уже всё знает.

4 · Оплата

Бот подтверждает заказ и принимает оплату (демо / провайдер).

5 · Списание

Остаток падает, журнал продаж пишется, сайт обновляется сам.
