ИИ-оператор, который
говорит первым

Он не «бот с кнопками в чате». Он звонит по сценарию, слышит собеседника через Whisper, отвечает голосом XTTS и ведёт диалог к цели — пока ты занимаешься делом.

Что внутри

🗣️

Живой голос (TTS)

Coqui XTTS v2: синтез с клонированием тембра по 6-секундному образцу WAV. Реплики генерируются на лету, работая на CUDA-ускорении.

🎧

Слух (STT + VAD)

faster-whisper turbo распознаёт живую речь клиента; детектор тишины и фоновый шум — не ломает сценарий, а возвращает его на нужный шаг.

📈

Воронка звонка

Сценарий загружается из .txt: шаги, ключевые слова, fallback. Импорт 10-секундно — меняешь скрипт, не трогая код.

💾

База звонков

SQLite: сессии, реплики, вердикты. Записи WAV сохраняются для разбор разговоров и обучения скриптов.

📦

Портативный агент

Экспорт .agent.json одним файлом: сценарий + голосовой образец + настройки. Перенос на другую машину за минуту.

🖥️

Панель оператора

Gradio-интерфейс: воронка, диалог, тесты голоса, экспорт. Запуск одной кнопкой на своём GPU.

Место под реальные скриншоты твоей сборки — просто замени img/tts-flow.svg и tts-hero.svg

Стек

Python 3.11 PyTorch 2.5 + CUDA Coqui XTTS v2 faster-whisper (turbo) Gradio 5 SQLite + WAV-экспорт numpy / librosa / pydub
